Which exercise: the one with the next set still to do: where your last logged set was if it has sets left, else the next one in the session. Before the first set it's the first exercise, Set 1. Once every set is in, the line reads All sets done and Finish stays.
The dot: Apple doesn't let anything on the lock screen move except the clock, so the dot stays still. The running clock is what shows it's live.
The bar: sets done out of the sets planned. Rogue sessions have no plan, so no bar.
Finish: a link, so it shows from iOS 16.1, as the tap does. It opens the app on the wrap-up.
