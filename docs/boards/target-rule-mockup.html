2. What the fix changes

The rule as you settled it stays (4 and 10 Nov): a set heavier than the target, reps inside its range, makes that weight the target for the weeks after. What changes is only that a raise has to stay backed by a set that is still there, and by the same lift.

4. A target not reached in a few sessions

Say Finlay had typed 150 for week 7 himself. "Not reached" counts back from the latest session until one reached the target (a set at that weight or more, reps inside the range), never past the day the coach last typed it; at 3 in a row it shows. Swaps, rogue sessions and Couldn't train neither count nor break the run. The NOW week and the later weeks still asking that figure show it, never a done week. The client sees nothing new.
