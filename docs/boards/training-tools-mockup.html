Training: the tools, with structure

Today the tools are spread four ways: sentences on the week line ("Apply to weeks 3–4", "Copy Week 2 here", "Copy from…"), a session's in its ⋯ (Duplicate session, Apply to remaining weeks), an exercise's in its ⋯, and drag handles. The same action has different words in each place. The idea: two actions, the same icon everywhere, on every level. Copy (the copy mark) puts something here or somewhere else this week; Apply forward (the arrow to a line) carries it into the weeks after. The weeks, the counts and the "what changes" live in the menu and its confirm, never on the button.

A · One tool group per level, icons with a word

The week line ends in one white capsule: Copy | Apply, then Columns and KG | LBS as now. Apply's small ink count is how many later weeks it would change (2); when nothing would change, it greys out instead of vanishing, so nothing moves. A session row gets the same two icons, on hover, before its marks: copy and apply, then the chat and ⋯. An exercise row: video, substitutes, chat, ⋯. Same icon, same meaning, every level.

B · The same two tools, each a menu that says where

A, and a tap on Copy or Apply opens the one floating list (the ⋯ look) with every way of doing it, so nothing is hidden in another place: Copy has into this week (from Week 1, 3) and to a new week (today's + Week → Copy); Apply has the weeks it would change, with what changes on its confirm (today's preview, kept). Session ⋯ keeps only Message and Delete; the copy/apply items move to the icons.

C · B, plus picking several at once

For copying exercises around: a box shows in the grip's place on hover; tick one or more exercises (or sessions) and a dark bar comes up at the foot with what can be done to all of them: Copy to… (another session, this week or a later one), Move to…, Apply forward, Remove. Esc or ✕ clears it. The most power, one new thing to learn.
