Workout as a sheet, A

Every exercise open on one page you scroll. A set counts only when you tap its tick: typing never logs it and nothing moves by itself. Four screens: logging, the ⋯, your note, and a swapped exercise.

What the ⋯ holds
  • Warm-up: adds a W row above set 1, its tick amber.
  • Substitute today: the swap, with the library search as now.
  • Your note: a note on this exercise for next time (seat height, grip, the machine). It shows under Finlay's, with the pen, every time the exercise comes back; Finlay sees it too.
  • Send a photo or video, when Finlay hasn't asked for one (when he has, it's the line under the name, as now).
Under the last set: + Add a set and − Remove a set, as today.
The tick: a circle, grey while the row is empty, ink once both boxes have a number, a green ring and check once tapped (amber for a warm-up), never filled. Tapping it again unlocks the set to fix it.
PB: a green PB ring between the reps and the tick, the moment a set beats the heaviest earlier set inside the rep range. Typed back down, it goes. The change on last time sits on each figure: +10 green, −1 rust.
